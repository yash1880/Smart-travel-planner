# ✈️ Smart Travel Planner

A **modern and responsive web app** built using **HTML, CSS, and JavaScript** that helps users plan their trips easily by calculating daily spending suggestions based on their total budget and travel days.

---

## 🌍 Live Demo
You can try it locally by opening the `index.html` file in your browser.

---

## 🧠 Features

- 🏖️ Input your **destination**, **budget**, and **total days**  
- 💰 Automatically calculates **per-day spending** suggestion  
- 🎨 Clean **glassmorphism UI** with gradient background  
- ⚡ Smooth **animations** using CSS  
- 📱 Fully **responsive** and simple design  

---

## 💻 Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure of the app |
| **CSS3** | Styling, gradients, and animations |
| **JavaScript (ES6)** | Logic and interactivity |
| **Google Fonts (Poppins)** | Elegant typography |
